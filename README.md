# opencode-freellmapi

Плагин OpenCode, который при старте синхронизирует каталог моделей [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi) в селектор моделей OpenCode. Версия портирована на **OpenCode V2** (проверено на 2.3.2).

## Что делает

1. Читает `baseURL` и `apiKey` из опций плагина.
2. Запрашивает `GET {baseURL}/models` с заголовком `Authorization: Bearer <apiKey>`.
3. Забирает **весь** каталог роутера, нормализует имена и лимиты.
4. Регистрирует провайдера `freellmapi` (пакет `@opencode/ai/providers/openai-compatible`) с найденными моделями.
5. Периодически повторяет синхронизацию (`refreshMinutes`, по умолчанию 5 минут) и перезагружает каталог — выбирать и прописывать модели вручную не нужно.

Если FreeLLMAPI не запущен или ключ неверный, плагин молча ничего не добавляет — запуск OpenCode не ломается.

## Установка

Добавьте плагин в `opencode.json` / `opencode.jsonc` (глобальный конфиг на Windows: `%USERPROFILE%\.config\opencode\opencode.json`):

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    {
      "package": "D:/opencode-freellmapi",
      "options": {
        "baseURL": "http://127.0.0.1:3001/v1",
        "apiKey": "{env:FREELLMAPI_API_KEY}"
      }
    }
  ]
}
```

`package` — путь к каталогу плагина (можно абсолютный, можно относительный к файлу конфига). Вместо `{env:...}` можно указать ключ строкой.

Перезапуск не нужен: OpenCode перечитывает конфиг и плагины автоматически. Принудительно — `/reload`.

## Где взять `baseURL` и `apiKey`

* **Серверная установка / Docker** — `http://127.0.0.1:3001/v1`. Единый ключ `freellmapi-…` лежит в дашборде на странице **Keys**.
* **Desktop-приложение FreeLLMAPI** — обычно `http://127.0.0.1:31415/v1`; точный порт смотрите в трее / настройках приложения. Ключ показывается во всплывающем окне трея.

## Опции

| Опция | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `baseURL` | да | — | База OpenAI-совместимого API FreeLLMAPI, вместе с `/v1`. |
| `apiKey` | да | — | Единый ключ FreeLLMAPI. |
| `refreshMinutes` | нет | `5` | Интервал повторной синхронизации каталога, минуты. |
| `includeUnavailable` | нет | `true` | Показывать модели, которым в роутере не хватает провайдерского ключа. |

## Поведение

* В список попадает весь каталог FreeLLMAPI. Модели с `available: false` тоже показываются — у них к имени добавляется `— no provider key` (или `— unavailable`). Выбрать такую модель можно, но запрос к ней вернёт ошибку, пока в дашборде роутера не добавлен ключ провайдера.
* Модели без флага `available` считаются доступными (не все сборки FreeLLMAPI его отдают).
* `limit.context` берётся из `context_length` / `context` / `context_window`, иначе 1 048 576.
* `limit.output` берётся из `max_output_tokens` / `max_tokens`, но не больше контекста; иначе 65 536.
* Повторяющиеся `id` схлопываются.

## Отличия от исходного плагина

* Портирован с V1 API (`config`-хук, ключ `plugin`) на V2: `Plugin.define`, `ctx.provider.transform`, ключ `plugins`.
* Провайдер создаётся самим плагином, отдельный блок `provider.freellmapi` в конфиге больше не нужен.
* Лимиты контекста/вывода и фильтрация `available` стали терпимее к разным ответам FreeLLMAPI.
